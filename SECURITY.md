# Security policy

## Reporting

Report vulnerabilities privately through GitHub Security Advisories. Do not open public issue with exploit details, tokens, account data, or submission data.

Include affected version, reproduction steps, impact, and suggested mitigation when known. Remove personal data and secrets from evidence.

## Supported versions

Project is pre-alpha. Only latest commit receives security fixes until first tagged release.

## Operator responsibilities

Use HTTPS, unique 32-byte-or-longer session secret, restricted filesystem permissions, encrypted off-host backups, current dependencies, and trusted loopback reverse proxy. Never collect passwords, payment card details, health information, government identifiers, or other highly sensitive data.
