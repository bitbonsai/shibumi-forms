# Shibumi Forms docs

Point a plain HTML form at one URL and every submission lands in a private dashboard. These pages cover the hosted service and the self-hosted core.

## Start here

1. [Connect your form](/docs/connect-form): register a page, copy the endpoint, paste the snippet.
2. [JSON API](/docs/json-api) if your client posts with `fetch` instead of a plain form.

## Run your own

- [Self-hosting](/docs/self-hosting) covers the container, compose file, and every environment variable.
- [Backup and restore](/docs/backup-restore) is two commands and one SQLite file.

## Reference

- [Limits](/docs/limits) documents hosted quotas and rate limits.
- [Security and data handling](/docs/security) explains what is stored, hashed, logged, and deletable.

Source and issues: [github.com/bitbonsai/shibumi-forms](https://github.com/bitbonsai/shibumi-forms).
