# About Shibumi Forms

> Why this exists.

Static sites are easy to publish but hard to make interactive. The moment you want a contact form, a waitlist, or an RSVP, you're pushed toward a hosted form builder, a heavier stack, paid tiers with artificial limits, or handing your visitors' data to who knows where.

Shibumi Forms is the small alternative. Point a plain HTML form at one URL and every submission lands in a private dashboard where you can read, export, add notes to, and delete it.

Plain HTML posts work without any client JavaScript, so your page stays exactly as fast and simple as it was.

- **One container**: self-host it, or use the hosted version, forever free.
- **One database**: a single SQLite database you can back up, move, or delete (when self-hosting; hosted data stays exportable as CSV and deletable at any time).
- **Plain HTML**: a form tag and an action URL. JavaScript optional.

The core is open source under the MIT license. Use it hosted for free, or run your own copy: <https://github.com/bitbonsai/shibumi-forms>.

The hosted service runs on donations ([Ko-fi](https://ko-fi.com/bitbonsai), [GitHub Sponsors](https://github.com/sponsors/bitbonsai), [Liberapay](https://liberapay.com/bitbonsai/)). If an endpoint attracts abuse or unusual load, we may pause it while we work out a fix. Report abuse to <info@shibumistack.dev>.

Shibumi (渋み): understated beauty through restraint. Shibumi Forms is part of [Shibumi Stack](https://shibumistack.dev), tools built on the idea that most software gets better by getting smaller.
